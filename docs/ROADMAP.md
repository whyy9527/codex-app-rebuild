# 实现路线

当前仅完成第 0 阶段。各阶段只有满足验收条件后才报告完成。

## 0. 独立项目骨架

- 私有仓库、架构、边界与实现路线。
- 不安装全局 hook，不自动恢复已暂停的视频任务。

## 1. 可审计执行记录

实现显式项目输入、候选父子关系、产物哈希、真实执行与评价回执、预算和恢复机制。

验收：可用小型非媒体任务运行并恢复；失败、未评审和通过可区分；不污染源输入；证据变更可检测。

## 2. 历史回放

实现冻结记录、逐步揭示、合法行动、已记录成本计量及策略对比。先采用明确标注的合成夹具测试协议，再使用真实记录验证。

验收：未来评分不可访问；未观察行动不生成虚构结果；相同历史和策略可复现回放结果。明确与论文机制的差异。

## 3. 视频参考分析适配

接入现有拉片能力，保存时间码、动作与声画证据及观察范围。没有声音或连续视频分析能力时显式报告缺口。

验收：观察可定位至原片；抽帧与完整视听审查明确区分；不把观察数量作为质量指标。

## 4. 剪辑探索试验

仅在获准恢复剪辑后进行。固定输入与约束，试验结构不同的候选，获得真实视听或用户反馈，形成可用历史。

验收：技术与审美结果分别记录；策略对比固定评价规则；在新的片段上检验历史回放发现，允许无改善或退步结论。

## 5. Codex 接入封装

提供经实际验证的使用 skill；按需求增加 MCP 适配或插件包。Hook 只有在确认支持的宿主接口、触发语义与清理行为后才加入。

验收：实际调用成功；卸载后无残留注册；不改变未经授权的全局配置；停止与预算边界有验证证据。
