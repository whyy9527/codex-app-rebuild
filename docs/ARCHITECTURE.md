# 架构草案

状态：待实现、待验证。这里描述拟议接口，不代表已有 API。

## 分工

Dream-RSI 启发探索控制与冻结历史上的策略回放。Cordis 启发组件依赖声明、作用域隔离和资源释放。Skill 描述如何使用工具；hook 只辅助提醒与短检查；插件是验证后交付的封装。

首版沿用 Python 工具链，通过 CLI 供 Codex 调用。不修改 Codex 内核，不宣称具备 Cordis 的形式化保证。只有出现明确动态装卸需求并通过适配试验后，才考虑直接引入 Cordis；不重复制造一套插件内核。

## 组件边界

| 组件 | 输入 | 输出及边界 |
| --- | --- | --- |
| 观察器 | 显式媒体输入及观察范围 | 时间码、证据及能力范围；抽帧不等于连续观看 |
| 候选生成器 | 当前分支、行动与约束 | 实际产物、执行回执、失败和成本 |
| 评审器 | 候选及固定评价约定 | 技术结果、视听或用户反馈；不能自动互相替代 |
| 探索策略 | 当前已揭示历史与剩余预算 | 新开分支、延续分支或停止 |
| 记录与回放器 | 真实执行与评审记录 | 可审计分支树；回放只揭示已记录的后续结果 |

## 最小记录

每个候选关联父候选、行动、策略版本、执行配置、产物哈希、评价证据及成本。人工偏好保留 A/B/无明显差异/无法判断，不擅自转换为精确分数。

回放世界冻结真实记录，不进行生成，不推测没有观察到的结果。动作无法映射到记录时返回 unsupported；停止条件与成本口径必须明确。首版确定性回放仅用于验证语义，不能据此宣称实现了论文全部机制。

## 运行约束

每次运行显式传入项目配置和预算，拥有独立输出目录与资源清理范围。停止生成组件后，记录与审查结果仍应可读。外部文件修改采用隔离副本或显式快照，不能把卸载插件等同于撤回所有副作用。

评价适配器不可被被评估的探索策略自行替换。采用新的评价规则时另起实验；策略在历史上的改进还需新的任务验证。

## 视频工作接入

复用既有视频仓库的拉片与审查工具，通过显式输入和适配器连接，不复制其私人素材或失败版本。先输出带时间码的参考观察，再在用户授权剪辑后建立候选分支。

参考观察不是剪辑效果评估。旧版视频已删除时，复盘文字不能冒充可回放的历史执行。缺少真实视听审查时，审美效果保持未验证。
