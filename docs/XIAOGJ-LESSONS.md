# 校管家试验：结论与 rebuild 框架迭代

用户于2026-10-13结束试验，并授权保留结论、预览及框架修订。产品仍未完整1:1；案例事实由[STATUS](../projects/xiaogj-web/STATUS.md)拥有，本文记录方法反例和迭代判断，不恢复案例或重写原生Goal生命周期。

## 得到的证据

本次在真实Web案例中使用了RSI历史池、同池可执行策略回放及实际再部署，并将发现接入共同E2E和前后端实现。这证明链路可用，未证明它在全站复刻上更快、成本更低或足够完整。多个两场景池都从0.20到0.21，主要差别来自零投入／质量达到1后的停止策略；不能把重复分数解释为持续发现新需求。局部14项通过与严格图像失败、未实现提交／持久化同时存在。

公开代码可启动，真实数据、账号、素材和完整历史仍依赖私有输入。用户无需全量数据，早先全目录搬运尝试因此停止；不能继续以原版158／204总数伪装候选十行样本，也不能由数据例外推出其他体验可以降低要求。

## 本轮已修改的方法

| 真实反例 | 失败机制 | 现有所有者与修订 |
| --- | --- | --- |
| 勾选后点击清空没有清空 | 在整页AX匹配到背景同名文字 | RSI要求限定实际弹窗／区域；案例v2已独立复做验证 |
| 刷新后守卫拒绝、密码提醒、主页入口迟到 | 单次观察把过渡态当最终状态；刷新并非恢复业务页 | RSI区分来源、就绪及实际恢复路径，只在准备阶段有界等正确来源；业务守卫不放宽 |
| 标题出现但没有目录行 | captions稳定不等于数据返回 | RSI要求动作所需实际记录／输入就绪，而非标题或固定等待 |
| 输入数量读成javascript:void(0)，再读为空 | 链接Value与字段Value混淆；字段数字也可能在AX名称 | RSI保留原文与cell Value，限定目标字段；失败后先用真实原文离线检查新解析，再冻结协议 |
| 后台原生Promise跨工具返回失败 | 工具执行上下文已结束，不能继续原生操作 | RSI要求原生调用在有效上下文内await，长操作用明确调用边界，不新增续跑任务机 |
| 数值通过、整图失败，Tab后横向滚动不同且有悬停提示 | 视口相同但状态／滚动／焦点不同 | WORKFLOW要求报告可比性限制并修准备，保留原始像素失败，不用语义通过冒充视觉通过 |
| “数据不用全量复刻”后Goal正文不能编辑 | 宿主只有创建与状态接口 | WORKFLOW要求同步项目目标、记录最新用户范围优先；禁止假完成后重建Goal |
| 用户停止后仍可能被自动Goal续跑 | 结束试验不等于达成目标 | WORKFLOW要求按宿主停止；可做明确授权的预览／复盘，不恢复探索 |
| 预览只打开网页，人类不知道点在哪里；可视窗口缩闪且目标在画外 | 启动成功不等于可观看的E2E；模拟视口和实际窗口不同，采集过程干扰播放 | WORKFLOW补入人类观看要求；案例提供普通速度巡演、鼠标／点击／焦点提示、动作前滚动和实际窗口尺寸，可视播放不逐章节截图 |
| 单个页面历史文件遗漏后续报名探索 | 页面历史与RSI池不是同一个记录来源，不能把未记录当未探索 | RSI补入只读可视化边界；案例从rebuild.json指向的当前池校验后生成ECharts树，保持各世界真实parent，不创造连接或完成率 |

这些规则写入[WORKFLOW](../workflows/rebuild/WORKFLOW.md)和[RSI](../workflows/rebuild/RSI.md)现有方法所有者，没有新增Goal文件、任务状态机、评分器或重复技能。旧失败协议和截图原样保留在案例私有历史，公开证据文件保留路径和终态。

收尾验证见[可视E2E预览](../projects/xiaogj-web/evidence/2026-10-13-human-preview.md)及[探索树展示](../projects/xiaogj-web/evidence/2026-10-13-exploration-tree.md)。复盘中的原生采集器抽取、比较前置条件判定、需求级汇总和真实分支策略效果验证仍未实现，分别对应Roadmap已有条目；补充方法要求和生成树不改变这些结论。

## 仍需迭代的框架成果

1. **减少观察器复制与真实采集试错。** 本次多个独立冻结版本重复了加载、来源、恢复和解析代码。现阶段只修了方法要求；还没有提取共同原生采集器。应从这些已验证消费者抽取恢复／AX字段读取的最小共用能力，并用保存的实际反例验证，不先设计统一浏览器管理层。
2. **把比较前置条件接到判定。** 当前整图工具能严格比较像素，但这些案例未提供充分的滚动／悬停一致性事实。后续需由驱动采实际状态，比较器在状态不一致时给出不可比原因，保留原始测量；不能给像素加容差来绕过。
3. **按完整用户旅程选下一步。** 本次在同一局部功能上做多轮两探针协议，主旅程提交、持久化和大量业务页仍空缺。方法现已要求对照完整旅程选择失败／未知；尚未实现需求级汇总，不能拿断言数或RSI分数当进度百分比。
4. **验证探索策略改变了什么。** 已有真实完整池回放与部署，但固定发现顺序、有限探针会把收益压缩为停止效率。后续需在实际未访问分支和观察器漏采上检查策略的选择效果；是否降低质量、成本和耗时仍无结论。消融继续只在产品完成后进行。

上述待办由[Roadmap](ROADMAP.md)连接，属于未完成成果。此次未实现这些能力，也未将预览成功当作产品或方法完成。
