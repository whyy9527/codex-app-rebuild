## 原生模型续跑

在显式临时项目中使用当时默认 GPT-6.1-Sol medium，未改模型。通过原生审查启用三项项目 Hook，保留已有全局 Hook。原生 MCP verifier 额外要求一次会话级授权，等待包含在总墙钟记录中；没有人工修改答案或发送续跑提示。

实际顺序：SessionStart → 模型启动有限任务 → 第一次真实验收 fail（1 != 2）→ 模型 checkpoint → 原生 Stop 返回继续决定 → 宿主注入 hook_prompt → 模型读取反馈、保留预算并修改 answer.py → 第二次真实验收 pass → 任务 complete → 最后 Stop 无继续决定。任务用两次尝试，宿主报告 92.108 秒（含工具审查等待）。冻结测试摘要保持不变。

[native-smoke.json](native-smoke.json) 保存任务、Hook、预算、实际用量和文件；[native-smoke.events.jsonl](native-smoke.events.jsonl) 保存筛选后的真实工具/消息事件，不包含内部推理或账号数据。TUI 显示 0.162.0，非交互 shell 返回 0.139.0，按实际观测分别记录，未猜测统一版本。费用未知。

该 smoke 用人为设置的单值错误检验宿主续跑链路，只证明这次宿主能在有限反馈下继续并停止。尚未证明多阶段 App 探索自动完成、跨语言 UI 验收、Duolingo 业务正确性、视觉质量或任何泛化收益。真实业务消融仍须另外登记并执行。
