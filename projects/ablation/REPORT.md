按 Git 跟踪的 capabilities/runtime/workflows 下 Python 文件计数，生产代码由 42 文件、2547 行缩至 13 文件、607 行。精简后全回归 13 项通过。原生 app-server 验证目标项目能发现 MCP，未安装的另一个项目不能发现。安装器现在仅写目标项目 .codex；本机旧全局的本工具 MCP 和四个 Hook 条目已移除，其他配置逐项核对保留，旧任务状态保留。
