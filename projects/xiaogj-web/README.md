# 校管家 Web 复刻

校管家 TMS 的本地复刻试验，采用用户指定的 realus-ops 技术栈。试验已结束，尚未达到完整 1:1；范围、验证结论与未完成项见 [案例结论](STATUS.md)。

在已准备本地数据库和私有输入的本机，双击 **预览.command**，或从仓库根运行：

```sh
python3 -m projects.xiaogj-web.tools.preview
```

双击默认启动**正常速度的可视 E2E 功能巡演**，数分钟：独立本地账号登录 → 首页／待办／周期图表／配置草稿 → 学员查询、分页、详情页签 → 报名课程／物品选择 → 数量和优惠金额联动。画面有黄色鼠标箭头、点击扩散圈、输入框焦点提示、章节说明和暂停／继续按钮；巡演结束后保留浏览器供手动查看，关闭该浏览器结束预览。断言失败会停在现场，不跳过失败。操作前先滚动到目标，停稳并展示鼠标位置后再点击。可视播放使用实际窗口尺寸，不逐章节截图；每次结果保存在忽略目录 `private/preview/tours/`，快速无头验证另保存截图。

只想手动打开网页可加 `--serve-only`；只验证服务启动可加 `--check --no-open`；已有构建可加 `--skip-build`。终端中按 Ctrl+C 退出，只关闭本次启动的服务。巡演自动读取独立本地账号 `private/local-auth.json`，不会使用原版账号。

巡演只展示本地已实现功能，不连接原版，不点击报名提交；不代表完整 1:1 或原版／候选共同验收通过。

新检出环境缺少私有数据库、账号与素材时不能直接复原本机内容；程序会报告缺失，不生成假数据或连接原版。准备方法见 [SETUP.md](SETUP.md)。
