# 查询探索、RSI 再部署与共同场景

本轮实际进入原版学员信息管理，仅查询和翻页，没有保存原版业务数据、偏好或密码。分页采集默认正式学员及跨校区条件下的 222 条实际记录，不代表休学、非正式学员或其他校区的数据全集。业务字段、号码、截图和会话均保存在忽略的私有目录。

## 原版发现及保留的失败

原版“重置”只清空条件，原有查询结果保留；再提交空查询才恢复默认结果。无匹配结果保留表头并显示空提示，分页栏消失。原生输入曾丢失字符，驱动改为粘贴并读取实际输入验证，不提交错误探针。旧准备过程遗漏空查询，基线精确检查失败；旧观察器要求分页栏存在，遇到空结果失败。失败目录均保留，没有改弱断言或覆写历史。

首次查询树和共同场景虽然取得精确数据事实，截图却被弱密码提示遮挡，因此不能证明正常可见旅程通过。通过原版弹窗内的“取消”文本控件关闭提示，未输入或修改密码；标题从 AX 消失且截图无遮挡后，使用新固定协议重新采集。旧协议 `rsi-query-occluded.json` 和 v3 驱动只用于解释原始历史，当前入口使用 v4。新驱动在密码提示存在或当前窗口不是原版时停止。

候选 AX 将总数、每页条数、页码合成一段，原版分成多段；初版共同驱动漏采此状态并报 unavailable。v2 驱动读取同样的数字事实，断言保持不变。另有一次标签切换中断，独立浏览器／标签绑定失败，均没有冒记为通过。

## 实际 RSI 链

当前 `rebuild.json` 连接固定协议、真实池和回放回执：

- `private/rsi-visible-collect-20261012`：实际采集 4 个非根节点，含连续三级和另一个根分支；每次发现后独立重跑已累积查询。
- `private/rsi-visible-baseline-20261012`：在完整冻结池读取原策略全部 rho 轨迹，分数 0.45。
- `private/rsi-visible-revision-20261012`：原策略与修订策略在同一完整冻结池比较；修订版在 rho=0 不调用，达到固定协议质量 1 后停止。分数 0.46，最大投入时 3 次调用达到同样质量，原策略用 4 次。
- `private/rsi-visible-redeploy-20261012`：原版标签未选中，守卫拒绝执行，进程实际失败，没有完成的新世界。
- `private/rsi-visible-redeploy-v2-20261012`：恢复原版后通过选中池重新 collect；池保留 2 个世界，新世界含 3 个非根节点，独立分数依次为 1/3、2/3、1。实际世界策略哈希等于选中策略文件，池、历史证据和快照完整性校验通过。

这些分数只表示三个固定查询要求的探索质量，不能证明视觉、全站覆盖或产品完成。新世界进入后续完整池回放，不丢弃旧世界，也不永久限于这三个查询。

## 实现与实际验收

候选使用 MySQL 中实际采集的全部 222 条记录，按原始顺序分页、查询；无法确认性别的 18 条保持 unknown，不编造男女。重置保留查询结果，空结果隐藏分页。姓名首字母、模糊匹配和其他筛选语义仍需继续观察。

API 实测遍历 23 页，合并后的每个字段及顺序等于私有采集数据；学号、电话、无匹配三个查询的记录及总数匹配。Vite 代理首屏匹配。第一次事务导入报 P2028 启动超时，数据库实际仍有 10 条；核验 MySQL 和应用连接后再次实际导入 222 条成功，没有修改迁移或伪造成功。重启编译后的 API 后才运行上述查询检查。

共同场景 `student-query-scenarios.json` 由同一个原生驱动执行，期待值仅交给独立比较器：

- 无遮挡原版 `private/e2e-reference-query-v2-20261012`：13 项行为断言通过。
- 候选 `private/e2e-candidate-query-v4-20261012`：相同契约摘要，13 项行为断言通过。

截图人工比较仍显示侧栏颜色与标记、列宽、性别图标位置及其他前端差异；本轮没有宣称严格像素通过。首页已有严格视觉失败仍保留。查询驱动不是全部 E2E，登录、权限、详情、写入、其他业务旅程、持久化、媒体与更多输入方式仍未完成。

原生 Goal 仍拥有完整 1:1 目标；`preflight` 连接齐全只说明方法接线和回执通过检查。


学员前端模具 `students-frontend-contract.json` 覆盖基线、学号结果及空结果的三张内容区严格整图、原生截图尺寸、查询／重置角色和实际表头文本。首次原版校验失败揭示表头 AX 含排序字体字形；据原版实际文本补全契约，没有从事实中删除字形。修订后原版校验 19 项通过；候选 5 项通过、14 项失败（3 张整图、2 个角色、9 个表头文本）。原结果及修订结果均保存，当前仍不满足前端验收。

本轮构建、类型检查及 Prisma 生成共 7 项通过，首页状态测试 3 项通过。完整仓库单元测试 90 项通过，`git diff --check` 通过；这些检查不抵消上述真实前端失败。
