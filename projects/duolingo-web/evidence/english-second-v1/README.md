观察到12道正常题和3道挑战，不能据此推定所有课都会替换末3题，或只凭连续正确数推导后台规则。何种状态触发挑战、是否请求了新的公开内容、其它轨迹都仍未知。回放器新增实际DOM题型核对，在继续用静态内容动作前明确停止分歧；同类型内容变化仍需进一步核对，单加type检查不能证明模型完整。
