# Duolingo 网页观察计划

状态：独立 Playwright 浏览器已完成首批真实观察；本文件仍是计划，证据归属观察记录。记录日期 2026-10-10。

## 范围与入口

参考入口为 https://www.duolingo.com/ 。先检查实际页面、登录状态、界面语言和可访问课程，优先使用可恢复的访客学习路径。平台版本以可见版本或观察日期记录，未显示则 unknown。当前不创建账号，不改变现有账号课程、购买或订阅。

首批范围由可访问的一个短课确定：进入课程、选择题或拼句、提交前的空答案边界、正确/错误反馈、下一题、退出及返回。题型和规则必须实际出现后才能转成验收，不假定每条路径都可访问。第二批专门寻找首批遗漏，优先检查错题重练、退出是否保存、刷新恢复及结算到学习路径的状态关联。

## 从证据到冻结批次

观察证据 → 行为项及前置状态 → 单一场景动作与预期 → 原版适配实际执行 → 原版回执 → 冻结批次 → Swift 原生动作适配。以上各步有实际产物后才推进；不能以本清单充当规格或给 unknown 补上断言。

线上原版通常没有任意夹具注入和完整重置接口。只有实际可操作的访客重开、课程重练或可恢复前置状态才能用于原版验收。若无法回到同一状态，报告 unavailable，缩小可比较范围，或把已观察规则另外建成明确标记的 local_reference；本地参考不等于线上原版，也不覆盖未观察的服务器规则。原版与本地参考的结果分开报告。

数据夹具只控制我们拥有的原创题库与候选应用存储，不能声称它已注入 Duolingo。跨端比较使用相同业务场景与统一断言，题面映射及允许差异在冻结前明示；不能把两份独立标准称作同一 E2E。Swift 核心测试、原生 UI 验收、视觉审查分别记录。
