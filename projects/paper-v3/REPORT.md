# 第三阶段：十轮自我迭代

完成十轮由当前 Codex 主会话实施的源码修改，使用项目内部的验收记录、源码快照和审计工具逐轮验证。每轮固定验收条件下均为 fail→pass，十轮完整源码清单均与对应提交匹配；最终 60 项测试通过。

这次主要提升工具的完整性与可用性，没有新增十次独立模型策略修订，也没有证明探索质量提高。

## 十轮修改与证据

| 轮次 | 修改前的实测缺口 | 修改后验收 |
| --- | --- | --- |
| 1 | 历史被拒策略没有重新参选入口 | 全部历史源码去重后可重新选择；旧策略能在构造的新世界胜出 |
| 2 | 开发器只比较原策略和最新提案 | 完整池参与开发和部署，旧提案胜出也能部署 |
| 3 | 相同 prompt 在两臂复用，难区分独立响应 | 实验组请求范围分离，回包复用次数明确记录 |
| 4 | CLI 未启动等失败缺少回执 | 启动、超时和输出校验异常保留状态；可持久写入回执 |
| 5 | 模型目录被误当成可调用性依据 | 有界真实预检要求运行声明，未认证回包不能算可用 |
| 6 | 仅有五例饱和训练任务 | 可复现且不重叠的训练/验证实例，排列相同视为同一问题 |
| 7 | 缺少新实例上的实际执行验证 | 冻结算法在新实例逐题执行，保留不可行结果，不据验证集选策略 |
| 8 | 复制目录中断后无法恢复 | 先登记待处理状态、原子发布目录；注入中断后恢复成功 |
| 9 | 审计器仍只回放原策略和新提案 | 反馈携带完整候选池，审计能独立重建池选择 |
| 10 | 缺少新阶段结果审计与持平判定 | 核对十轮提交来源，并把真实验证持平记为无观察到的收益 |

[回执](receipts.json)含 23 条记录：20 条固定配对、1 条完整回归、1 条报告计数修正后的两项定向复核和1条早期导入检查。早期检查 `s01-before` 的测试实例随后修正，因此不参与配对；第一轮正式配对为 `s01-baseline`→`s01-after`，原检查仍保留。不同轮验收不同，fail→pass 只能证明对应缺口修复，不能计算为统一基准提升率。单元测试中的模型、评价和崩溃注入均为明确测试替身，不计作真实模型实验。

[汇总审计](summary.json)逐轮核对固定验收摘要、父子关系和源码与提交的匹配；十轮无源码不一致。

## 使用新能力重选真实历史

对上阶段两份真实冻结世界上的十份实际策略源码进行了完整池重选，结果仍保留原策略，平均回放分数约 0.31875。没有新的策略更新。完整轨迹见 [池重选结果](pool-reselection.json)。

构造测试证明“旧提案可以重新胜出”的机制；实际历史没有出现这种变化。这两类证据分别解释，不能把测试构造当成真实策略收益。

## 独立实例验证：没有观察到收益

使用算法在上阶段已经冻结的源码，再生成验证实例。三个固定种子 41、73、109，各 8 道验证题，共 24 题；题目按重量多重集合去重，与生成的训练组不重叠。算法没有根据这些结果重新修改或选择。

| 冻结算法 | 平均分 | 执行失败 | 相对 FFD 的胜/平/负 |
| --- | ---: | ---: | --- |
| FFD | 0.9100499 | 0 | 基线 |
| BFD | 0.9100499 | 0 | 0 / 24 / 0 |
| 贪心认证加精确回退 | 0.9100499 | 0 | 0 / 24 / 0 |

[逐题记录与源码](validation.json)保存全部实例、源码摘要、执行规则摘要和可行性证据。没有为了获得改善而换掉这组验证题。分数采用重量下界/箱数；重量下界可能不可达，因此低于 1 不直接意味着算法没有找到最优解。

结论仅为这些新实例上没有观察到算法收益。没有验证策略效率，没有随机模型重复、论文九项基准或实际视频任务，因此不支持一般效果或实用性提升幅度的结论。

## 模型状态与运行限制

[真实 CLI 预检](model-preflight.json)仍失败，退出码 1，保留诊断摘要；token 和费用未知。本阶段独立模型策略修订数为 **0**。交互回包通道仍可用，不能称为无人值守模型研究系统。

请求范围分离避免同一实验不同组自动共享回包，但不能隔离主会话记忆，也不能独立认证模型配置。复用计数是单请求记录，尚非跨进程并发安全的计费总账。

目录准备阶段的中断恢复已注入实测；生成器返回后到状态落盘之间的任意崩溃、外部模型费用的恰好一次语义和全流程截止时间仍未解决。受限 Python 仍不是操作系统安全沙箱。

## 可复用入口

从仓库根执行，输入均显式给出：

```bash
python3 -m workflows.paper.preflight --model <explicit-model> --timeout 20 --out artifacts/preflight.json
python3 -m workflows.paper.reselect --experiment projects/paper-v2/experiment.json --out artifacts/reselection.json
python3 -m workflows.paper.validation --program ffd=<workspace> --program candidate=<workspace> --seed 41 --seed 73 --seed 109 --count 8 --out artifacts/validation.json
python3 -m workflows.paper.stage_report --receipts projects/paper-v3/receipts.json --validation projects/paper-v3/validation.json --preflight projects/paper-v3/model-preflight.json --out artifacts/stage-audit.json
```

当前的 stage_report 专用于本阶段十轮，reselect 用于上阶段含已采用提案的实验报告；不是任意项目通用报告格式。新模型实验仍使用 experiment/requests 交接，不自动恢复旧运行。

本阶段没有恢复视频任务，没有安装 hook、修改全局认证、接入付费 API 或公开仓库。本次没有媒体修改。

下一步应先解决独立模型调用，再冻结更有区分度的任务设计并预先规定对照；当前验证结果不能支撑继续堆策略变体或宣布论文复现成功。
